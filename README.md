# Caseflow

A Remotion-powered Latin sentence lab for Dr. Plate’s Level 2A class. One checked sentence, two word orders, and six preview stages.

Run npm ci, then npm run dev for the browser app or npm run studio for Remotion Studio. npm test checks stable grammatical identities and connection geometry at every frame. npm run build produces the static site.

This app illustrates teacher-reviewed data; it does not parse arbitrary Latin. References are linked inside the app.
